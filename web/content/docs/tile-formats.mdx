# Tile Formats

TileForge supports three output formats for generated tiles.

## Input Formats

TileForge accepts the following image formats as input:

| Format | Free | Pro | Notes |
|--------|------|-----|-------|
| PNG | Yes | Yes | Best quality, supports transparency |
| JPEG | Yes | Yes | Smaller files, no transparency |
| WebP | Yes | Yes | Modern format, good compression |
| TIFF/GeoTIFF | No | Yes | Standard GIS/satellite imagery format |

<CalloutCard title="TIFF/GeoTIFF Support" variant="info">
  TIFF and GeoTIFF files are supported on the server-side API and worker for Pro users. The browser-based WASM processor does not support TIFF to keep the bundle size small.
</CalloutCard>

## Output Formats

### XYZ Tiles

The standard slippy map tile format used by most mapping libraries. Tiles are organized in a `z/x/y.png` directory structure.

```
tiles/
├── 0/
│   └── 0/
│       └── 0.png
├── 1/
│   ├── 0/
│   │   ├── 0.png
│   │   └── 1.png
│   └── 1/
│       ├── 0.png
│       └── 1.png
└── ...
```

**Best for**: Direct serving from a file system or static hosting (S3, CloudFront, Nginx).

## PMTiles

[PMTiles](https://github.com/protomaps/PMTiles) is a single-file tile archive format. All tiles are packed into one `.pmtiles` file with an optimized index for HTTP range requests.

```bash
# Serve with any static file server
python -m http.server 8080
```

```javascript
// Load in MapLibre GL
import { Protocol } from "pmtiles";
const protocol = new Protocol();
maplibregl.addProtocol("pmtiles", protocol.tile);
```

**Best for**: Simple deployment, serverless hosting, or when you want a single portable file.

<CalloutCard title="Recommended Format" variant="tip">
  PMTiles is the recommended format for most use cases. It combines the simplicity of a single file with efficient random access via HTTP range requests.
</CalloutCard>

## ZIP

All tiles are bundled into a standard ZIP archive with the same directory structure as XYZ tiles.

```bash
# Extract and serve
unzip tileset.zip -d ./tiles
```

**Best for**: Downloading and extracting locally, or when you need a standard archive format.

## Format Comparison

| Feature | XYZ | PMTiles | ZIP |
|---------|-----|---------|-----|
| Single file | No | Yes | Yes |
| HTTP range requests | No | Yes | No |
| Direct serving | Yes | Yes | Extract first |
| Leaflet support | Native | Via plugin | Extract first |
| File count | Many | 1 | 1 |

## Server Processing Output

When using the API (Pro), both ZIP and PMTiles are generated automatically in a single pass. You can download either format after processing completes.
